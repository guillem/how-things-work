# Data sources and licences

Every external dataset, data-derived file and third-party asset the site ships, with its licence
status. Compiled 2026-10-15 from the headers of the data files in `src/routes/*/`, the build
scripts in `scripts/data/*/`, the two `DATA-LICENSES.txt` files, `MENDELEEV-LICENSE.txt`, and the
credits in each topic's `steps.ts` and scenes. All 100 routes were checked. Nothing here was
re-checked against the sources' own terms pages: "licence as stated" is what the repository
records.

How the status is decided:

- **OK**: public domain, CC0, PDDL, MIT, BSD, or a stated "free to use with citation", and the
  source is credited.
- **Attribution/share-alike obligations**: CC BY, CC BY-SA, ODC-BY. The row says what is required
  and whether the page and the file meet it. A row stays here even when the obligations are met.
- **Non-commercial**: the terms allow only non-commercial use (CC BY-NC-SA, REE's terms, a
  permission for non-commercial educational use).
- **Unconfirmed**: no licence found, terms page unreachable, or the data was read from a mirror
  or copy instead of the original. The original's licence is noted where known.

The repository's own licences are `LICENSE` (MIT, the code) and `LICENSE-CONTENT.md` (CC BY 4.0, the text and illustrations); this file covers the third-party data. "Page" means the explainer as served; "file" means
the data file's header in the repository (headers do not survive into the built JavaScript).
